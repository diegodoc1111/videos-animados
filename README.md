# La skill con la que Claude hace mis videos animados (reel-motion)

Tutorial gratis en español de [@soydiegoosorio](https://instagram.com/soydiegoosorio) para instalar **reel-motion** en Claude Code: videos 100 % animados con voz en off (sin grabarte) o tu video grabado convertido en motion graphics.

**Página:** https://diegodoc1111.github.io/videos-animados/
**La skill:** https://github.com/diegodoc1111/reel-motion (licencia MIT)

## Fuentes verificadas (4-nov-2026)
- reel-motion: instalador `scripts/instalar.py`, modo sin presentador `scripts/sin_presentador.py` (voz con ElevenLabs, llave en `~/.config/reel-motion/.env`) y plantilla `plantilla/build_sin_presentador.py`, probados el 4-nov-2026.
- Llaves de ElevenLabs (Settings → API Keys, permiso Text to Speech): https://elevenlabs.io/app/settings/api-keys
- Instalación de Claude Code: https://code.claude.com/docs/en/setup
